# 제휴병원 로컬 샘플 사진

기존 승인된 가상 사진을 재사용한다. 원본은 `D:/hanhwa/outputs/garamin-service-home-app-20261009/revision-16/assets/`의 `synthetic-general-clinic.png`, `synthetic-dental-clinic.png`, `synthetic-clinic-exterior.png`다. 실제 제휴 병원을 식별하는 사진이 아니다.

`goodmorning-cheongju-exterior.jpg`는 실제 제휴병원 굿모닝한방병원 청주의 홈페이지(https://gmcheongju.com/) 갤러리 '병원 전경' 사진이며 병원 허락을 받아 사용한다. 1200px 폭으로 줄이고 촬영 위치·기기 메타데이터를 지웠으며, 지나가는 사람이 보이지 않도록 아래쪽을 잘랐다.

`EXPO_PUBLIC_HOSPITAL_DEMO=true` 로컬 설치본의 가상 병원 데이터에서만 사용한다. 목록·소개·상세는 기존 `photoUrl` 경로와 이미지 컴포넌트를 재사용한다. 사진 원본과 의미는 해당 revision-16/assets/README.md를 따른다.
