# 굿모닝한방병원 청주 규정 요청 목록

작성일: 2026-10-20. 현재 앱의 "간병 시작 전 확인할 것"(lib/hospital-care.ts)은 다른 병원의 공개 입원 안내를 참고한 **초안**이다. 병원 홈페이지(gmcheongju.com)에는 입원·간병인 규정이 없었다 [사실]. 아래 원문을 받으면 항목마다 출처 조항을 붙여 다시 쓴다.

## 1. 병원에 요청할 원문

| # | 자료 | 담당 부서(추정) | 쓰는 곳 |
|---|---|---|---|
| 1 | 입원 안내문(입원 수속, 준비물, 퇴원 절차) | 원무과 | 준비물, 시작 당일 절차 |
| 2 | 보호자·간병인 출입 규정(출입증, 인원, 시간) | 간호부 | 출입 등록 항목 |
| 3 | 간병인 준수사항(병동 내 금지 행위, 의료행위 금지 범위, 감염관리) | 간호부 | 간병인 안내, 의료행위 항목 |
| 4 | 면회 규정과 감염 예방 지침(마스크, 발열 확인) | 감염관리 담당 | 감염 예방 항목 |
| 5 | 반입 금지·제한 물품 목록 | 간호부 | 반입 항목 |
| 6 | 병동별 연락처와 간병인 도착 시 보고 절차 | 각 병동 간호사실 | 상담원 병동 연락 |
| 7 | 낙상·사고 발생 시 보호자·간병인 보고 절차 | 간호부 / 적정관리 | 시작 후 사고 규칙 |
| 8 | 외부 간병인 허용 여부와 조건(병원 지정 간병업체 여부) | 원무과 | 서비스 가능 여부 자체 |

8번이 가장 먼저 필요하다. 병원이 외부 간병인을 받지 않거나 지정 업체만 허용하면 이 흐름 전체가 달라진다 [추론].

## 2. 현재 초안 항목과 확인 필요 원문

| 현재 항목 | 근거 상태 | 대체할 원문 |
|---|---|---|
| 입원 병동과 호실을 상담원에게 알려 주세요 | 모두온 운영 필요 | 6 |
| 간병인 출입증과 보호자 등록 방법은 간호사실에서 확인 | 다른 병원 안내 참고 | 2 |
| 복용 약·알레르기·거동 상태는 간병인에게 직접 | 모두온 운영 필요 | 3 |
| 개인 위생용품 준비 | 다른 병원 안내 참고 | 1 |
| 반입 제한 물품은 병원 규정을 따름 | 다른 병원 안내 참고 | 5 |
| 면회·마스크 등 감염 예방 | 다른 병원 안내 참고 | 4 |
| 의료행위는 간병인이 할 수 없음 | 의료법 27조 1항 취지 [사실: 무면허 의료행위 금지] | 3 |
| 간병 비용·정산은 상담원과 확인 | 모두온 운영 필요 | 운영 계약 |

## 3. 받은 뒤 할 일

1. 원문을 받으면 항목마다 "출처: 입원 안내문 ○쪽" 형식의 근거를 `lib/hospital-care.ts` 주석과 이 문서에 연결한다.
2. 병원 간호부에 최종 문구 확인을 요청한다. 확인 전까지 외부 검증 상태는 "대기"다.
