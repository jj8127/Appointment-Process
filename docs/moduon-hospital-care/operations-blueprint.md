# 간병 연결 운영 블루프린트

작성일: 2026-10-20. 상담 원본 기록을 아직 받지 않았다. 이 문서의 단계·시간은 **[가정]**이며, 원본 기록을 받으면 실측값으로 바꾼다.

## 1. 원본 수집 양식

현재 간병 문의가 어떻게 처리되는지 재구성하려면 최근 1~3개월의 문의를 아래 형식으로 모은다. 이름·전화번호·질환명은 넣지 않는다. 사례 번호만 쓴다.

| 열 | 형식 | 예시 | 이유 |
|---|---|---|---|
| case_id | C-001 | C-001 | 사례 구분 |
| channel | 전화/카톡/병원 소개/앱 | 카톡 | 유입 경로 |
| received_at | YYYY-MM-DD HH:MM | 2026-09-03 21:40 | 접수 시각 |
| first_contact_at | YYYY-MM-DD HH:MM | 2026-09-04 09:10 | 첫 연락까지 시간 |
| caregiver_found_at | YYYY-MM-DD HH:MM | 2026-09-04 13:00 | 간병인 확보 시간 |
| decided_at | YYYY-MM-DD HH:MM | 2026-09-04 13:20 | 확정 또는 거절 시각 |
| care_started_at | YYYY-MM-DD HH:MM | 2026-09-05 09:00 | 실제 시작 |
| outcome | 확정/일정 조정/거절/보호자 취소/연락 두절 | 확정 | 결과 |
| fail_reason | 자유 기술(개인정보 제외) | 주말이라 간병인 연락 안 됨 | 실패 원인 |
| care_type | 24시간/주간 | 24시간 | 수요 구분 |
| handled_by | 담당자 역할(이름 아님) | 상담원 A | 담당 부하 |

수집 방법: 상담원 휴대폰 통화 기록, 카톡 대화 시각, 기존 엑셀 접수표를 사례 번호로 맞춘다. 원본은 회사 안에 두고, 위 표만 전달한다.

## 2. 서비스 블루프린트 (목표 흐름)

| 단계 | 보호자 | 앱·시스템 | 상담원 (앞단) | 뒷단 (간병인·제휴 간병업체) | 병원·병동 | 목표 시간 [가정] |
|---|---|---|---|---|---|---|
| 1 탐색 | 병원 상세 확인 | 명칭·주소·전화 표시 | - | - | - | - |
| 2 요청 | 희망일·형태·연락 시간 선택 | 요청 저장, 관리자 알림 | - | - | - | 즉시 |
| 3 첫 연락 | 전화 받음 | "첫 연락" 시각 기록 | 동의 확인, 상태·병실 청취 | - | - | 운영시간 내 30분 |
| 4 간병인 확보 | 대기 | "확인 중" 표시 | 조건 전달 | 간병인 수락 | - | 운영시간 내 4시간 |
| 5 확정 | 확정 알림·주의사항 확인 | 확정 시각 기록, 회원 알림 | 일정·비용 안내 | 배정 확정 | 간병인 출입 등록 안내 | 첫 연락 후 당일 |
| 6 시작 | 간병인 맞이 | "간병 시작" 시각 기록 | 시작 확인 전화 | 병동 도착 | 간호사실 등록 | 희망일 |
| 7 사후 | 불만·변경 요청 | - | 접수·교체 조정 | 교체 간병인 | - | 24시간 내 응대 |

## 3. 예외 처리 규칙 (초안)

| 상황 | 규칙 [가정, 사용자 결정 필요] |
|---|---|
| 야간(22:00~08:00)·주말 요청 | 자동 응답 없이 접수만 한다. 첫 연락 기준은 다음 운영 시작 후 30분. 당직 담당자를 정하면 24시간 기준으로 바꾼다. |
| 간병인 부족 | 4시간 안에 확보 못 하면 "일정 조정"으로 다른 시작일을 제안한다. 제안 불가면 "진행 어려움"과 사유를 보낸다. |
| 같은 날 요청 | 접수 즉시 상담원에게 전화 우선 처리. 당일 확정 불가 시 1시간 안에 알린다. |
| 보호자 취소 | 확정 전에는 앱에서 취소. 확정 후 취소는 상담원이 간병인에게 즉시 알리고 취소 사유를 기록한다. 취소 수수료는 계약 구조 확정 후 정한다. |
| 연락 두절 | 연락 시간대에 2회 전화, 문자 1회. 24시간 무응답이면 "진행 어려움(연락 두절)"으로 닫고 알림을 보낸다. |
| 시작 후 불만 | 24시간 안에 상담원이 보호자·간병인 양쪽 통화. 교체 요청은 제휴 간병업체에 즉시 전달. 사고·폭언 등은 별도 기록·보고. |
| 중복 요청 | 같은 회원의 답변 대기 요청은 3건까지(구현됨). 상담원이 같은 환자 건을 하나로 합친다. |

## 4. 확인이 필요한 결정

1. 간병 제공 주체: 모두온 직접 소개인지, 제휴 간병업체(가족간병 제휴사)인지. 법적 쟁점 D와 연결된다.
2. 운영시간과 당직 체계: 첫 연락 기준(30분)을 적용할 시간대.
3. 간병인 확보 목표 시간과 일정 조정 기준.
4. 취소 수수료와 정산 방식.
