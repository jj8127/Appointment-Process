# 간병 연결 외부 검증 계획

작성일: 2026-10-20.

## 1. 보호자 사용성 시험 (3~5명)

대상: 최근 1년 안에 가족 입원·간병을 준비해 본 보호자. 모두온 직원·FC는 제외한다.
방식: 대면 또는 화면 공유. 진행자는 도와주지 않고 관찰만 한다. 실제 개인정보 대신 시험 계정과 가상 환자 정보를 쓴다.

| 과제 | 시작 화면 | 성공 기준 | 측정 |
|---|---|---|---|
| T1 청주에서 굿모닝한방병원을 찾아 상세를 연다 | 모두온 홈 | 도움 없이 2분 안 | 시간, 막힌 지점 |
| T2 내일부터 24시간 간병을 요청한다 | 병원 상세 | 도움 없이 요청 완료 | 시간, 잘못 누른 횟수 |
| T3 요청 상태가 무엇인지 말한다 | 예약 화면 | "접수됨"의 뜻을 맞게 설명 | 이해 여부 |
| T4 확정 알림을 받고 시작 전 확인할 것을 연다 | 알림(시험 발송) | 알림 탭 후 주의사항 펼침 | 성공 여부 |
| T5 요청을 취소한다 | 예약 화면 | 도움 없이 취소 | 성공 여부 |

### 기록표

| 참가자 | 과제 | 성공(Y/N) | 시간 | 막힌 지점(그대로 인용) | 진행자 메모 |
|---|---|---|---|---|---|
| P1 | T1 | | | | |

판정: 과제별 성공률 80% 미만이거나 같은 지점에서 2명 이상 막히면 화면을 고친다.
